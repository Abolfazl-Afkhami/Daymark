# Daymark ⏱️

> **Personal Habit Tracking & Productivity Dashboard**  
> داشبورد تک‌کاربره، موبایل‌محور و لوکال برای برنامه‌ریزی، پیگیری عادت‌های تحصیلی و مهندسی، ثبت جلسات تمرکز، و تحلیل پیوسته عملکرد با تقویم دو زبانه (فارسی شمسی و انگلیسی میلادی).

برای مطالعه سند کامل مشخصات فنی، معماری داده و مدل‌های ریاضی استریک‌ها، فایل [SPECIFICATION.md](./SPECIFICATION.md) را ببینید.

---

## 🛠️ تکنولوژی‌های به‌کار رفته (Tech Stack)

- **فریم‌ورک:** Next.js 14 (App Router) + React 18
- **زبان:** TypeScript با حالت Strict و `noUncheckedIndexedAccess`
- **پایگاه‌داده:** SQLite در حالت WAL از طریق `better-sqlite3` و Drizzle ORM
- **استایل‌دهی:** Tailwind CSS با متغیرهای طراحی و پشتیبانی دوطرفه (RTL / LTR)
- **موتور تقویم:** پشتیبانی کامل و قطعی از تقویم جلالی (شمسی) و میلادی
- **آزمون‌ها:** Vitest برای تست‌های واحد موتور محاسبات دامنه

## 🚀 راه‌اندازی و اجرای سریع (Quick Start)

### ۱. نصب وابستگی‌ها
```bash
pnpm install
```
*(یا `npm.cmd install`)*

### ۲. مقداردهی اولیه پایگاه‌داده (Database Seed)
برای ایجاد جداول و اضافه شدن ۴ حوزه اصلی زندگی (مطالعات تحصیلی، هوش مصنوعی، برنامه‌نویسی، رشد فردی):
```bash
node scripts/seed.js
```

### ۳. اجرای سرور توسعه (Development Server)
```bash
pnpm dev
```
سپس مرورگر را باز کرده و به آدرس زیر بروید:  
👉 **http://localhost:3000**

### ۴. اجرای تست‌های خودکار (Unit Tests)
```bash
pnpm test
```

```text
│   ├── app/                   # روت‌های Next.js App Router

│   │   │   ├── analytics/     # آمار و تحلیل‌ها

└── package.json
```
